账号与 token 都有效（`GET /v1/owners` 能返回 `My Workspace`），仓库也已公开（匿名 `git ls-remote` 可拉到 `f90c5ec`），唯一缺口是**账号需要绑定一张卡**（免费实例不扣费，只是验证支付方式）。

```powershell
$env:RENDER_API_KEY = (从 config/deploy.env.bat 读取)
curl -s -X POST https://api.render.com/v1/services `
  -H "Authorization: Bearer $env:RENDER_API_KEY" `
  -H "Content-Type: application/json" `
  -d "@config/render-create.json"
```

### Koyeb：备选，需要 API token + GitHub App

Koyeb 不要求绑卡，但建服务需要两样东西：

1. API token：<https://app.koyeb.com/account/api> → Create API token（Full access）；
2. 授权仓库：<https://github.com/apps/koyeb> → Install → 选择 `tkRRRRRR/Campus-Event-Management-System`。

拿到 token 后（仓库根已备好 `config/koyeb-create.json`）：

```powershell
$env:KOYEB_TOKEN = "<token>"
curl -s -X POST https://app.koyeb.com/v1/services -H "Authorization: Bearer $env:KOYEB_TOKEN" `
  -H "Content-Type: application/json" -d "@config/koyeb-create.json"
```

载荷里已经把端口设为 8000（平台会注入 `PORT=8000`，应用读 `${PORT:8080}`）、区域 `was`、实例 `free`、健康检查 `/api/ping`、8 个环境变量（库连接、JWT 密钥、JAVA_OPTS）都填好了。

## 三、换后端域名后必须做的一步

前端的环境变量写死指向了 `campus-activity-api.onrender.com`。如果后端最终跑在别的域名（Koyeb 是 `xxx.koyeb.app`），需要改这两项并重新部署：

```powershell
cd web
$env:HTTPS_PROXY = "http://127.0.0.1:40517"   # 本机 api.vercel.com 需走代理
vercel env rm VUE_APP_API_BASE production
printf 'https://<新域名>' | vercel env add VUE_APP_API_BASE production
vercel env rm VUE_APP_FILE_BASE production
printf 'https://<新域名>' | vercel env add VUE_APP_FILE_BASE production
vercel deploy --prod --yes
```

## 四、已知限制

2. **免费实例休眠**：Render 免费服务 15 分钟无请求会休眠，首次访问要等 30~60 秒。答辩现场建议仍用便携包，线上只作为"确实部署过"的证据。

4. **密钥管理**：`config/deploy.env.bat`、`config/render-create.json`、`config/koyeb-create.json` 含 token 与数据库口令，均已加入 `.gitignore`，不要提交；换机器时手动复制。
