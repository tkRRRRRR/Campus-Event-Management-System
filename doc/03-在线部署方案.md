# 在线部署方案（Vercel 前端 + 云端后端 + SQLPub 数据库）

> 目标：老师随时点开一个网址就能用；答辩现场再退回到本地单 jar，双保险。

---

## 一、整体架构

```
                    ┌──────────────────────────────┐
   浏览器  ───────► │  Vercel（静态托管，https）      │
                    │  Vue2 + Element UI 构建产物     │
                    └──────────────┬───────────────┘
                                   │ axios → https://api.xxx
                    ┌──────────────▼───────────────┐
                    │  Render（Docker，https，免费）  │
                    │  SpringBoot 单 jar              │
                    └──────────────┬───────────────┘
                                   │ JDBC over TLS
                    ┌──────────────▼───────────────┐
                    │  SQLPub 云端 MySQL 8.4         │
                    │  共享实例，0.5GB，30 连接上限    │
                    └──────────────────────────────┘
```

**关键：前后端都必须是 https。** 如果前端在 Vercel（https）而后端在本地 `http://localhost:8080`，浏览器会按 Mixed Content 直接拦截请求，控制台一片 `blocked:mixed-content`。这是这类部署最常翻车的地方。

## 三、后端：Render 部署

### 前置条件
- Dockerfile 已就绪（`./Dockerfile`）
- `render.yaml` 已就绪（Blueprint 模式）

### 步骤

1. 把项目推到 GitHub（`config/`、`tools/`、`target/` 已在 `.gitignore` 里）
2. Render 控制台 → **New → Blueprint** → 选仓库
3. 按 `render.yaml` 提示填写四个环境变量：
   - `DB_HOST=mysql6.sqlpub.com`
   - `DB_PORT=3311`
   - `DB_NAME=tkrrrrrr`
   - `DB_USER=tkrrrrrr`
   - `DB_PASSWORD=你的密码`
   - `DB_SSL=true`
4. 部署完成后访问 `https://<你的服务名>.onrender.com/api/ping`，返回 `{"code":200,...}` 即成功

### 免费版注意
- **15 分钟无请求会休眠**，下次访问冷启动约 30~60 秒。演示前 1 分钟先自己点一下热启动。
- 内存 512MB，Dockerfile 里已经把堆上限压到 `-Xmx256m`。
- 免费实例共享 CPU，第一次启动可能较慢，属正常。

### 备选平台

| 平台 | 免费额度 | 国内访问 | 备注 |
|---|---|---|---|
| Render | 有（会休眠） | 一般 | 文档最全，推荐先试 |
| Koyeb | 有（512MB） | 一般 | 不休眠，但有额度限制 |
| Zeabur | 试用金 | 快 | 付费后适合长期用 |
| 阿里云函数计算 FC | 有免费额度 | 快 | 国内最稳，但要配自定义运行时 |
| 腾讯云 CloudBase 云托管 | 有免费额度 | 快 | 需要实名认证 |
| 学生云服务器 | 约 ¥50/年 | 快 | 最省心，答辩前买一个月 |

Dockerfile 是通用的，上面任何一个平台都能用。

## 四、前端：Vercel 部署

### 关键文件（前端建好后放入 `frontend/`）

`vercel.json` —— history 路由必须加，否则刷新子页面 404：

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

`.env.production` —— 指向 Render 的 https 地址：

```
VUE_APP_API_BASE=https://<你的服务名>.onrender.com
```

### 步骤

```bash
cd frontend
npm i -g vercel        # 或者 npx vercel
vercel                 # 首次：登录 + 关联项目
vercel --prod          # 生产部署
```

构建命令 `npm run build`，输出目录 `dist`，Vercel 会自动识别 Vue CLI 项目。

### 域名：vercel.app 在大陆被 DNS 污染

Vercel 官方知识库承认大陆无节点、可能很慢或打不开。两种处理：

1. **绑自定义域名**（推荐）：域名 CNAME 指向 `cname-china.vercel-dns.com`，比默认解析快不少
2. **接受限制**：老师用境外网络/校园网访问，或在答辩时用本地形态演示

## 五、三处必须对齐的配置

| 位置 | 配置 | 不对齐的后果 |
|---|---|---|
| 后端 CORS | 放行 `https://*.vercel.app` + 自定义域名 | 前端报 `CORS policy` 错误 |
| 前端 `VUE_APP_API_BASE` | 填后端 https 完整地址 | 请求打到 localhost，全部失败 |
| 后端 `PORT` | 读环境变量，不写死 8080 | Render 健康检查失败，判定部署失败 |
