# 接口文档（v1.0）

> 本文件是前后端联调的唯一依据，同时作为论文附录 A 的素材。
> 所有接口前缀 `/api`，请求体 `Content-Type: application/json;charset=UTF-8`，
> 仅 `/api/auth/login`、`/api/auth/register`、`/api/ping` 免登录（白名单见 `config/WebMvcConfig.java`），**其余接口全部需要**请求头 `Authorization: Bearer <token>`。因此前端采用"登录后才进入主界面"的形态。

## 0. 通用约定

### 0.1 统一返回体

```json
{ "code": 200, "msg": "操作成功", "data": {} }
```

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 业务校验失败 / 参数不合法（msg 可直接展示给用户） |
| 401 | 未登录或 token 失效 → 前端清理登录态并跳登录页 |
| 403 | 已登录但无权限（角色不符） |
| 404 | 资源不存在 |
| 500 | 服务端异常（msg 统一为"系统繁忙，请稍后再试"） |

### 0.2 分页结构

```json
{ "pageNum": 1, "pageSize": 10, "total": 23, "records": [ ... ] }
```

分页入参统一为 `pageNum`（从 1 开始）、`pageSize`（默认 10，上限 50）。

### 0.3 角色常量

`STUDENT` 学生、`ORGANIZER` 组织者、`ADMIN` 管理员。管理员可调用组织者接口。

### 0.4 时间格式

出入参统一 `yyyy-MM-dd HH:mm:ss` 字符串。

### 0.5 状态码表

**活动 status**：0 草稿、1 待审核、2 已发布（报名中）、3 已驳回、4 已取消、5 已结束

**报名 status**：1 已报名、2 已签到、3 已取消、4 爽约、5 待审核

**用户 status**：1 正常、0 禁用

**签到方式 checkin_type**：1 扫码/签到码、2 组织者补签

## 1. 认证 `/api/auth`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/auth/login` | 登录 | 登录 |
| POST | `/api/auth/register` | 登录 | 注册（只能注册为学生） |

**登录入参**：`{ "username": "admin", "password": "123456" }`
**登录出参**（`LoginVO`，前端据此存 token 和基础信息，再调 `/api/user/info` 取完整资料）：

```json
{ "token": "xxx.yyy.zzz", "userId": 1, "username": "admin", "realName": "系统管理员", "role": "ADMIN" }
```

**注册入参**：`{ username, password, realName, studentNo }`（username 6~20 位，password 6~20 位）

## 4. 活动 `/api/activity`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/activity/page` | 登录 | 已发布活动分页 |
| GET | `/api/activity/{id}` | 登录 | 活动详情（含统计与当前用户报名状态） |
| POST | `/api/activity` | ORGANIZER | 发布；`draft=false` 直接提交审核，`draft=true` 存草稿 |
| PUT | `/api/activity/{id}` | ORGANIZER | 编辑（草稿、待审核、已驳回可改；改后重新进入待审核） |
| PUT | `/api/activity/{id}/cancel` | ORGANIZER | 取消活动（活动开始后不可取消），批量通知报名者 |
| GET | `/api/activity/my` | ORGANIZER | 我发布的活动 `status, keyword, pageNum, pageSize` |
| GET | `/api/activity/audit/page` | ADMIN | 待审核列表 |
| PUT | `/api/activity/{id}/audit` | ADMIN | 审核 `{ pass: true/false, remark }`，驳回时 remark 必填（兼容 `reason`） |

**活动分页入参**：`pageNum, pageSize, categoryId, keyword, status, sort`
`sort` 取值：`latest`（默认，按开始时间倒序）、`hot`（按报名人数倒序）

**活动列表项**（`ActivityListVO`，封面字段是 `coverUrl`）：

```json
{ "id": 1, "title": "2026 年校园十佳歌手大赛", "coverUrl": "/upload/xx.jpg", "summary": "…",
  "categoryId": 1, "categoryName": "文艺演出", "location": "大学生活动中心",
  "startTime": "2026-11-20 19:00:00", "endTime": "2026-11-20 21:30:00",
  "signupDeadline": "2026-11-18 18:00:00", "capacity": 200, "signedCount": 31, "remaining": 169,
  "status": 2, "organizerId": 2, "organizerName": "李静", "regStatus": null,
  "auditRemark": null, "createTime": "…" }
```

`regStatus`：当前用户的报名状态（null 表示未报名，1/2/3/4/5 见 0.5）。

**活动详情**（`ActivityDetailVO`）额外字段：

```json
{ "content": "活动详情", "auditRemark": null, "needAudit": 0,
  "joinedCount": 37, "checkinCount": 33, "absentCount": 1, "cancelCount": 2,
  "avgScore": 4.6, "reviewCount": 12, "qualityScore": 86.5, "regStatus": 2 }
```

注意：报名数总量字段叫 `joinedCount` / `checkinCount` / `absentCount` / `cancelCount`（不是 checkedCount）；
「我的报名状态」叫 `regStatus`（不是 myRegistrationStatus）。是否可报名由前端按 `status===2 && remaining>0 && regStatus===null` 判断。

**发布的入参**：

```json
{ "title": "…", "coverUrl": "…", "summary": "…", "content": "…", "categoryId": 1,
  "location": "…", "startTime": "2026-12-01 19:00:00", "endTime": "2026-12-01 21:00:00",
  "signupDeadline": "2026-11-30 18:00:00", "capacity": 100, "needAudit": 0, "draft": false }
```

**封面上传**：

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/activity/cover` | ORGANIZER/ADMIN | `multipart/form-data`，字段名 `file`；支持 jpg/jpeg/png/gif/webp，≤5MB；返回 `{code:200, data:"/upload/cover/xxx.png"}` |

上传成功后把返回的相对路径写入活动入参的 `coverUrl` 字段即可；静态资源由 `/upload/**` 直接访问。

## 5. 报名 `/api/registration`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/registration/{activityId}` | 登录 | 报名（原子占名额，可能返回"名额已满"） |
| DELETE | `/api/registration/{activityId}` | 登录 | 取消报名 |
| GET | `/api/registration/my` | 登录 | 我的报名 `status, activityStatus, keyword, pageNum, pageSize` |
| GET | `/api/registration/activity/{activityId}` | ORGANIZER/ADMIN | 报名名单 `status, keyword(姓名/用户名/学号), pageNum, pageSize` |
| PUT | `/api/registration/{registrationId}/audit` | ORGANIZER/ADMIN | 审核报名 `{ pass: true/false, reason }`，驳回时 reason 写入通知 |
| GET | `/api/registration/activity/{activityId}/export` | ORGANIZER/ADMIN | 导出报名名单 xlsx，可带 `status, keyword`，返回二进制流 |

**我的报名项**（`MyRegistrationVO`，`reviewed` 表示是否已评价，用于控制"去评价"按钮）：

```json
{ "id": 88, "activityId": 1, "activityTitle": "…", "coverUrl": "…", "location": "…",
  "startTime": "…", "endTime": "…", "signupDeadline": "…", "activityStatus": 5,
  "status": 2, "signupTime": "…", "checkinTime": "…", "checkinType": 1, "reviewed": true }
```

`activityStatus` 用来按"活动状态"过滤我的报名（例如查已结束的活动传 5）。

**名单项**（`RegistrationMemberVO`）：

```json
{ "id": 88, "userId": 101, "realName": "张三", "username": "2023000201", "studentNo": "20230201",
  "phone": "138…", "status": 1, "signupTime": "…", "checkinTime": null, "checkinType": null }
```

## 6. 签到 `/api/checkin`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/checkin/{activityId}/code` | ORGANIZER/ADMIN | 生成（或复用）签到码 |
| GET | `/api/checkin/{activityId}/code` | ORGANIZER/ADMIN | 查询当前有效码（**只读，不生成**） |
| POST | `/api/checkin/{activityId}` | 登录 | 学生凭码签到 `{ "code": "123456" }` |
| POST | `/api/checkin/manual/{registrationId}` | ORGANIZER/ADMIN | 手动补签 |
| GET | `/api/checkin/{activityId}/list` | ORGANIZER/ADMIN | 签到名单 `status, keyword, pageNum, pageSize` |
| GET | `/api/checkin/{activityId}/stat` | ORGANIZER/ADMIN | 签到统计 |
| POST | `/api/checkin/{activityId}/finish` | ORGANIZER/ADMIN | 提前结束活动并判定爽约，`data` 返回爽约人数 |

**签到码**：

```json
{ "activityId": 1, "code": "638662", "expireTime": "2026-11-20 19:30:00",
  "remainSeconds": 1780, "valid": true }
```

**签到统计**：

```json
{ "activityId": 1, "capacity": 200, "signedCount": 33, "checkedCount": 30,
  "absentCount": 1, "waitingCount": 2, "pendingCount": 0, "cancelCount": 2, "checkinRate": 90.91 }
```

签到规则：窗口 `[开始时间 - 30 分钟, 结束时间]`；活动结束后不能签到；爽约用户不能签到。

## 7. 评价 `/api/review`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/review/{activityId}` | 登录 | 提交评价 `{ score: 1~5, content, anonymous }` |
| GET | `/api/review/activity/{activityId}` | 登录 | 评价分页 `pageNum, pageSize` |
| GET | `/api/review/activity/{activityId}/stat` | 登录 | 评分分布 |
| GET | `/api/review/my` | 登录 | 我的评价 |
| DELETE | `/api/review/{reviewId}` | 登录/ADMIN | 删除（本人或管理员） |

**评价项**（匿名时后端脱敏：`userId=null`、`userName="匿名同学"`）：

```json
{ "id": 6, "activityId": 1, "activityTitle": "…", "userId": 102, "userName": "李嘉怡",
  "score": 5, "content": "…", "anonymous": 0, "createTime": "…", "mine": false }
```

**评分分布**：

```json
{ "avgScore": 4.0, "total": 2, "score5": 1, "score4": 1, "score3": 0, "score2": 0, "score1": 0,
  "myReview": { "score": 5, "content": "…" } }
```

限制：活动必须已结束（status=5），报名必须已签到（status=2），一人一条。

## 8. 统计 `/api/stat`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/stat/overview` | ADMIN | 平台总览 |
| GET | `/api/stat/organizer` | ORGANIZER/ADMIN | 我的活动总览（管理员看全平台） |
| GET | `/api/stat/category` | ORGANIZER/ADMIN | 分类分布 |
| GET | `/api/stat/trend?days=7` | ORGANIZER/ADMIN | 近 N 天报名/签到趋势（≤30） |
| GET | `/api/stat/top?limit=5` | ORGANIZER/ADMIN | 报名排行（≤20） |

**总览**（`PlatformStatVO`；活动状态字段带 `Count` 后缀）：

```json
{ "userCount": 74, "studentCount": 72, "organizerCount": 1, "bannedUserCount": 0,
  "activityCount": 8, "draftCount": 0, "pendingCount": 0, "publishedCount": 5, "finishedCount": 3, "canceledCount": 0,
  "registrationCount": 234, "pendingRegCount": 0, "signedUpCount": 168, "checkedCount": 56,
  "cancelRegCount": 2, "absentCount": 8, "checkinRate": 24.1,
  "reviewCount": 7, "avgScore": 4.0, "categoryCount": 5 }
```

`/api/stat/organizer` 返回 `OrganizerStatVO`，字段与上表相同但**不含** userCount/studentCount/organizerCount/bannedUserCount/categoryCount。

**分类分布**：`[{ "categoryId": 1, "name": "文艺演出", "activityCount": 2, "registrationCount": 83 }]`

**趋势**：`[{ "date": "11-14", "registrationCount": 17, "checkinCount": 15 }]`

**排行**：`[{ "id": 3, "title": "…", "categoryName": "学术讲座", "capacity": 80, "joinedCount": 61, "signedCount": 61, "status": 2 }]`

## 11. 系统参数 `/api/config`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/config/list` | ADMIN | 参数列表 |
| PUT | `/api/config/{id}` | ADMIN | 修改 `{ "configValue": "3" }` |

参数项：`{ "id": 1, "configKey": "violation_limit", "configValue": "2", "remark": "爽约次数上限" }`
整数类参数：`violation_limit`、`ban_days`、`checkin_code_minutes`、`activity_default_capacity`、`quality_weight_checkin`、`quality_weight_score`、`quality_weight_complete`（后三项为质量分权重，默认 40/40/20，计算时按三者之和归一）。
