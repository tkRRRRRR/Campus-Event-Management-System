基于 LAMP 架构的校园微活动管理平台的设计研究
王蕾 华北理工大学,河北 唐山 063000
摘要:学生的校园活动是校园生活中不可缺少的一部分,学生在参加活动的过程中不仅提高了能力,还能促进身心的健康发 展。但是很多学校的校园活动宣传的方位比较小,因此不能得到有效的评论信息,基于这种情况应该构建完善的网络管理系 统,因此本文就 LAMP 架构的校园微活动管理平台的设计进行了研究,对校园微活动管理平台的设计有一定的借鉴意义。 关键词:LAMP 架构;校园微活动;管理平台

在校园微活动管理平台设计的过程中采用 LAMP 框架结 构,可以充分利用网络平台的资源,建立相关的系统框架。 LAMP 框架结构体系具有资源占用量少,运行稳定的优点,可 以较好地应对大规模的并行访问,有利于提高系统的性能, 提高学生参与的积极性,促进校园微活动管理平台的发展。 1 LAMP 架构技术 校园微活动管理平台计划基于浏览器/服务器的模式 进行构建,从而使全校的学生都可以通过电脑或者智能移动 设备终端,对管理网站进行访问,通过访问来完成网站的使 用。为了提高系统的性能,减低开发的成本,实现校园微活 动管理平台的设计,可以采用 LAMP 架构方案。根据校园微 活动管理网站的需求,来要求硬件具备性能高、负载均衡的 要求,在选择软件的过程中,要求满足操作系统稳定,高性 能的特点,从而建立方便性能优良的数据库管理系统,同时 还要有高效的程序开发语言。 2 基于 LAMP 架构的校园微活动管理平台的设计 2.1 系统实际目标 设计校园微活动管理平台主要为了丰富学生的校园生 活,为校园管理提供信息化的软件,使参与校园活动的人可 以通过管理平台提高工作的效率使校园活动能够更好地举 行,同时,校园活动的参与者可以更好地与活动进行互动, 提高用户的关注度。 2.2 系统总体设计方案 基于系统的需求分析,并以系统的设计目标为指导,对 校园微活动管理平台总体设计方案进行讨论。该系统的总体 设计方案包括三个不同的角度,分别从平台所提供的功能, 平台的开发架构,以及平台的部署方案,对系统的总体方案 进行设计。 2.3 系统功能框架设计 设计校园微活动管理平台可以为不同类型的用户提供 所需要的功能,校园活动的组织者、活动参与者、学校管理 部门、系统管理员,是主要的参与者,根据不同的参与者, 校园微活动管理平台构建了不同功能的使用模块,主要包括 组织管理模块、活动参与模块、审批管理模块、系统管理模 块。为校园微活动管理提供了详细的系统框架设计,有利于 管理平台的构建。 2.4 系统逻辑框架设计 在校园微活动管理平台设计的过程中逻辑框架设计是 保证平台运行的主要保证,因此在设计系统逻辑框架的过程 中要采用分层的逻辑框架模式,不同的构架会被划分到不同 的层中,从而达到相互之间耦合的目的。系统分为界面层、 控制层、业务逻辑层、数据访问层,界面层主要是系统和参 与者之间的操作接口,管理参与者数据和操作的输入,并将 系统信息及时反馈给参与者,该层包括系统功能架构中所设 计各子系统的用户界面;控制层是界面层和业务逻辑层之间 的接口层,其主要作用是根据配置文件的信息,将用户的请 求发送给业务逻辑层的处理构件,并将业务逻辑模块处理的 结果在指定的界面中显示;业务逻辑层中包括了多个业务逻 辑功能模块,实现活动管理系统的各个功能,采用分层逻辑 框架主要为了达到性能分析中的需求,提高系统的可扩展性 和可维护性。
2.5 系统数据框架设计 系统的数据框架直接影响了整个系统的运行,是实现校 园微活动管理平台设计的重要依据,因此要建立完善的系统 数据库,由于校园微活动管理平台中的数据比较多,在存储 的过程中形成多个数据库,主要包括:活动信息数据库表、 参与学生数据库表、反馈信息数据库表等。 2.6 虚拟资源调度算法的设计 虚拟资源调度算法的设计是校园微活动管理平台中重 要的功能,虚拟资源调度算法的设计是实现是活动视频转播 功能的重要依据,可以使没有办法参加现场活动的学生可以 通过系统视频转播的功能还获得活动现场的相关信息,有效 分配了虚拟资源,实现为更多用户提供视频转播的服务。为 了进一步提高视频转播的性能,可以通过 Linux 系统构建完 善的虚拟资源调试平台,通过设计算法,提高对资源的分配 能力,充分发挥系统的价值。 在虚拟资源调度的过程中,通常是依靠用户对现场活动 需求的情况和系统运行的情况,实现资源的分配,提高了系 统的运行效果。在视频转播的过程中,会把不同活动现场视 屏资源点播信息存储在相关的数据库中,在除夕信息的过程 中可以通过 SQL 语言技术实现信息提取。在构建虚拟资源调 度算法构建的过程中主要是通过计算机的中央处理器 CPU 和 虚拟机的中央处理器 vCPU 进行控制,调度流程共分为三个 操作环节,包括预处理环节、执行环节、收尾处理环节。 处理环节的工作主要包括三个部分,首先要统计活动现 场视频的点播请求量,通过相关的计算得出需要的资源,并 且可以通过读取数据库的记录得出需要的资源;其次监控当 前虚拟集群节点资源的使用情况,充分掌握系统的整体负载 情况,系统资源调度模块中的系统资源可以帮助处理环节实 现相关功能;最后通过相关的数据,来构建相关的预测模型, 计算机中央处理器在使用的过程中实现对视频资源的请求。 执行环节是分配虚拟资源的重要环节,在分配资源的过 程中会通过处理环节中的预测结果与系统测值进行对比,根 据结果决定可以启动虚拟资源调度流程,从而实现对活动现 场的是转播功能,进一步维护系统的负载平衡。在执行环节 中的预测结果会保存在相关数据库,方便工作人员的分析。 收尾环节主要是完成虚拟资源的调度和分配工作,向系 统中其他的系统发出结束的信号,相关的系统收到了结束信 号后会启动复位流程,从而进入下一个处理周期。 3 结语 综上所述,校园微活动是校园活动中的重要组成部分, 学生在校园微活动的过程中不断提高自己的能力,因此要重 视校园微活动管理平台的设计,应用 LAMP 架构可以有效实 完成校园管理实际,实现校园管理的效果,促进校园微活动 管理的发展。 参考文献
