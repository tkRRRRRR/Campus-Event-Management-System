## 二、软件与部署

| 文件 | 说明 |
| --- | --- |
| ★ `release/CampusActivitySystem.zip` | 81.6MB，内含 jar、内置 JRE、数据库脚本、启动 bat 与使用说明；解压即用，不依赖本机 Java |
| `target/campus-activity.jar` | 单 jar，前端已打入 static；`java -jar` 启动，默认 8080 |
| `src/main/java/**` | 后端源码，8 个模块，60 个业务接口（详见附录 C） |
| `web/**` | 前端源码，Vue 2.7 + Element UI，21 个页面 |
| `db/schema.sql`、`db/indexes.sql`、`db/data.sql` | 建表、索引、演示数据（74 用户 / 8 场活动 / 239 条报名 / 7 条评价） |
| `scripts/` | 一键构建、打包、测试、演示准备脚本（见下表） |

脚本一览：

| 脚本 | 用途 |
| --- | --- |
| `scripts/build-all.ps1` | 前端构建 → 复制 dist → Maven 打包单 jar |

| `scripts/prepare-demo.ps1` | 演示前 5 分钟运行：创建临场活动、审核、报名、生成签到码 |
| `scripts/test-admin.ps1` / `test-checkin.ps1` / `test-review.ps1` / `test-contract.ps1` | 接口级回归（43 + 15 项断言等），封面与导出另见 TC-99~TC-104 |
| `scripts/ConcurrencyTest.java` | 50 并发对照实验，输出超卖与计数差异 |
| `scripts/build_thesis.py` / `build_docs.py` / `build_ppt.py` / `build_defense.py` | 论文、三份 Word、PPT、答辩材料的生成脚本 |

## 五、提交前检查

- [ ] 论文 docx 打开后确认目录页码已更新（右键目录 → 更新域 → 更新整个目录）。
- [ ] 封面填写：学院、专业、班级、学号、姓名、指导教师。
- [ ] 页眉、页边距、参考文献格式按学校模板核对（当前为 A4、上下 2.54cm、左右 3.17cm、正文宋体小四、1.5 倍行距）。
- [ ] 便携包在一台**未安装 Java** 的电脑上解压并启动，浏览器访问 `http://127.0.0.1:8080`。
- [ ] 现场演示前一天，按 `doc/08-演示脚本.md` 完整走一遍流程，包括 `prepare-demo.ps1`。
- [ ] PPT 用 `答辩PPT.pdf` 备用；U 盘同时放 zip、PDF、docx 三类文件。
- [ ] 论文与 PPT 中的数字一致：8 张表、60 个接口、21 个页面、104 条用例、50 并发对照（10/40/77ms 与 50/0/212ms）。
